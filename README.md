## Возможности

- Отображение поглощения на рейд-фреймах поверх полосы здоровья и входящего исцеления
- Чтение значения через `UnitGetTotalAbsorbs(unit)` и `VUHDO_getAbsorbOnUnit()`
- Отдельные цвета abs-бара при полном и неполном HP, а также при переполнении щита
- Раздельное отображение входящего исцеления: свои и чужие полосы
- Опциональная подсветка переполнения abs-бара (over-absorb glow)
- Выбор текстуры заливки abs-бара для полного и неполного HP
- Настройка интервала опроса поглощений (500–5000 мс)
- Автовключение отображения поглощений на Sirus при наличии `UnitGetTotalAbsorbs`
- Полезно ДЦ-жрецам для мониторинга эффектов `Слово Силы: Щит`, дополнительного поглощения от таланта `Божественное покровительство`, а также других эффектов поглощения

## Требования

- Клиент [Sirus.su](https://sirus.su) (Wrath 3.3.5)
- Основа: **VuhDo 2.23**
- Не устанавливайте параллельно стандартный VuhDo с Curse/Wago — используйте только эту версию

## Установка

1. Скачайте архив из [Releases](https://github.com/danilEl2/Vuhdo_Sirus.su/releases) (тег `v2.23.8-beta.3` / `v2.23.8` или новее).
2. Распакуйте папки `VuhDo` и `VuhDoOptions` в `World of Warcraft\Interface\AddOns\`.
3. Если установлен другой VuhDo — удалите или переименуйте его папки.
4. Перезагрузите интерфейс: `/reload`.

## Настройка

1. Откройте настройки VuhDo: `/vd`.
2. Включите отображение: **Общее → Входящее → «Поглощение»** (по умолчанию выключено).
3. Задайте текстуры abs-бара: **Общее → Входящее → «Настройки поглощений»** — «Поглощения (неполное HP)» и «Поглощения (полное HP)».
4. При необходимости настройте интервал опроса поглощений в том же разделе (рекомендуется 3000–5000 мс).
5. Настройте цвета: **Цвета → Режимы → «Абсорбы»** — отдельно для неполного и полного HP.

## История изменений

### v2.23.8-beta.3 (по сравнению с v2.23.8-beta.2)

- Исправлено: мигание/пропадание щита при бафах на max HP (sticky-кэш + soft-zero confirm)
- Исправлено: гонка UNIT_MAXHEALTH — стабилизация текущего HP ~0.2 с, без ложного damage flash
- Улучшено: опрос absorbs в бою (до EVENT_COUNT), dirty-queue для coalesced redraw
- Улучшено: fallback-библиотеки через `<Script>` (без `loadfile`), без подмены `_G.UnitGetTotalAbsorbs`
- Улучшено: over-absorb glow учитывает ориентацию бара (в т.ч. вертикальные)
- Улучшено: дефолт опроса absorbs 3000 мс; адаптеры переинициализируются при загрузке профиля

### v2.23.8-beta.2 (по сравнению с v2.23.8-beta)

- Добавлено: скорость плавной анимации HP — слайдер **Панели → Полосы → «Скорость»** (Медленно / Средне / Быстро)
- Улучшено: ширина abs-бара плавно lerp'ится отдельно от HP
- Улучшено: позиция щита каждый кадр считается от displayed HP (входящее без lerp)
- Исправлено: при уходе с полного HP overshield не схлопывается в 100–100, а пинится справа той же шириной

### v2.23.8-beta (по сравнению с v2.23.7-beta)

- Добавлено: плавная анимация полосы здоровья (опция **Панели → Полосы → «Плавно» / Smooth**, по умолчанию выкл.)
- Улучшено: при плавной анимации abs/incoming остаются у видимого края HP
- Улучшено: шкала HP/абсорба учитывает переполнение щита, но не сжимается из‑за большого входящего исцеления

### v2.23.7-beta (по сравнению с v2.23.6-beta)

- Исправлено: abs-бар на полном HP — щит рисуется поверх полосы по доле absorb/maxHP (без сжатия шкалы)
- Исправлено: over-absorb glow якорится к краю HP, если текстура абсорба скрыта/нулевой ширины

### v2.23.6-beta (по сравнению с v2.23.5-beta)

- Улучшено: смена специализации — активация раскладки при инициализации, защита от рекурсии, сохранение привязок при загрузке профиля
- Исправлено: границы панелей хранятся как имена SharedMedia (миграция со старых путей), корректный выбор текстуры рамки
- Исправлено: color picker больше не затирает соседние поля (file/edgeSize/insets у BORDER) при смене цвета
- Исправлено: «Применить ко всем панелям» копирует таблицы глубоко, без общего ссылочного состояния

### v2.23.5-beta (по сравнению с v2.23.4-beta)

- Добавлено: поддержка третьей специализации (SPEC_3) — автопрофили, раскладки заклинаний, корректная смена с сохранением привязок
- Улучшено: abs-бар при полном HP — overlay и over-absorb glow только при полном HP
- Улучшено: цвета поглощений и over-absorb glow включены по умолчанию

### v2.23.4-beta (по сравнению с v2.23.3-beta)

- Исправлено: abs-бар рисуется после входящего исцеления (как у Blizzard), устранены артефакты на стыках полос
- Добавлено: раздельные полосы входящего исцеления (свои/чужие) и настройки переполнения поглощения
- Добавлено: цвет входящего исцеления от других игроков в **Цвета → Режимы**

### v2.23.3-beta (по сравнению с v2.23.2-beta)

- Исправлено: abs-бар больше не «прыгает» к центру фрейма при большом входящем исцелении
- Добавлено: настраиваемый интервал опроса поглощений (**Общее → Входящее → Настройки поглощений**)
- Улучшено: на Sirus поглощения включаются автоматически при первом запуске
